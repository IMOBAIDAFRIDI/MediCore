The Hospital Management System (HMS) is a web-based application developed using PHP and MySQL. It is designed to efficiently manage hospital operations, including patient records, appointment scheduling, hospital management, vaccine information, digital medical reports, and administrative controls. The system provides an admin dashboard to manage hospitals, patients, and system requests, as well as a hospital dashboard for handling appointments and patient data. Patients can book appointments through both normal and instant booking systems. The application also supports digital medical reports with export functionality, a vaccine management module, secure login and logout mechanisms, and full MySQL database integration. Additionally, it supports network-based hospital requests to improve coordination and data management across the system.

The Hospital Management System is built using HTML, CSS, and JavaScript for the frontend, PHP for backend processing, and MySQL as the database. It runs on an Apache server environment such as XAMPP or WAMP. The project includes a database.sql file containing all required tables, including admins, hospitals, patients, appointments, vaccines, and reports. To install and run the project, the user must install XAMPP or WAMP, copy the project folder into the htdocs directory, create a MySQL database, import the database.sql file using phpMyAdmin, update the database credentials in the db_connect.php file, and then access the project through a web browser using localhost. The project follows a modular PHP structure with separate files for admin, hospital, and patient operations, making it easy to maintain and extend. This project is suitable for university final year projects, web engineering courses, and demonstrations of CRUD operations using PHP and MySQL.
